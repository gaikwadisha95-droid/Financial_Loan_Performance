# Financial_Loan_Performance
Financial Loan Performance Dashboard built using Microsoft Power BI to analyze loan amounts, annual income, interest rates, loan status, and borrower data through interactive charts, KPI cards, and filters.

##📊 Financial Loan Performance Dashboard | Power BI

#📌 Project Overview
The Financial Loan Performance Dashboard is a data analytics project developed using Microsoft Power BI. It helps analyze loan data and borrower information through interactive charts, KPI cards, and filters.
The dashboard provides an overview of loan amounts, annual income, loan status, employment length, loan terms, and borrower states.

#🎯 Project Objectives
Analyze overall loan performance.
Track key financial KPIs.
Compare loan amounts across employment-length groups and loan terms.
Analyze annual income by state and issue-date month.
Explore loan-related information using interactive filters.
Present financial data in a clear and understandable format.

#🛠️ Tools & Technologies
Microsoft Power BI Desktop
Data Analytics
Data Visualization
KPI Reporting
Interactive Dashboard Design

#📈 Key Performance Indicators (KPIs)
The dashboard includes the following KPI cards:
Total Annual Income – Sum of annual income in the selected data.
Total Loan Amount – Total loan amount recorded in the dataset.
Total Loans – Loan count based on the report's measure.
Average Interest Rate – Average interest rate displayed in the report.


#📊 Dashboard Visualizations

1. Loan Amount by Employment Length
Chart Type: Column Chart
Compares the total loan amount across different employment-length groups.

2. Total Accounts by Loan Status
Chart Type: Donut Chart
Shows how the sum of total accounts is distributed across loan-status categories.

3. Annual Income by Issue-Date Month
Chart Type: Line Chart
Displays the monthly pattern of summed annual income based on the loan issue date.

4. Annual Income by State
Chart Type: Bar Chart
Compares the sum of annual income across different borrower states.

5. Loan Amount by Loan Term
Chart Type: Pie Chart
Shows the distribution of total loan amount across different loan-term categories.

#🎛️ Interactive Filters
The dashboard includes these slicers:
Grade: Filter records by loan grade.
Verification Status: Filter records by verification category.
Issue Date: Select a date or date range.
These filters help users explore specific sections of the loan data.
